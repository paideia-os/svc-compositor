# svc-compositor v1.0.0 -- release manifest (source form)
#
# This is the human-readable source form of `manifest.pdxsig`. The
# release tool at pkgs.paideia-os mirror-push time (a) enumerates the
# artifact list below, (b) recomputes every BLAKE3-256 hash from the
# repo tree at the v1.0.0 tag, (c) writes the completed manifest into a
# binary `manifest.pdxsig`, and (d) invokes
#   paideia-pq-sign::sign_release_artifact(sk, manifest_path)
# once with the paideia-release-line Ed25519 secret key and once with
# the ML-DSA-65 secret key. The two detached signatures are appended to
# the manifest in the fixed layout below and the resulting
# `manifest.pdxsig` is pushed to
#   https://pkgs.paideia-os/main/svc-compositor/1.0.0/manifest.pdxsig
# alongside (in this case) the source tree only -- svc-compositor
# ships NO compiled service ELF at v1.0.0 (M1..M3 pipeline slice
# still open, see STATUS.md).
#
# Format mirrors mkfs.pdxfs's `release/manifest.pdxsig.txt` byte-for-
# byte in structure (this org's Wave F closer template).
#
# Reference:
#   design/paideia-as/v0.20-issue-1025-pq-signing.md         -- Hybrid,
#     sign_release_artifact, HybridSignature (Ed25519 || ML-DSA-65).
#   design/02-development-environment.md                     -- hybrid
#     release-artifact signature rationale (Ed25519 + ML-DSA-65).
#   design/tooling/plan.md                                   -- package
#     repository layout, `manifest.pdxsig` per version directory.
#   design/graphics/r102-user-plan.md                        -- M5-001
#     scope (dual-signed release + honest-witness M4 closer) for this
#     repo.
